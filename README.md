# 網路分享童書

第一本：**為什麼ㄅㄆㄇ**  
圖文／**備課抱佛腳**

靜態童書書架與閱讀器，適用於 GitHub Pages。支援手機滑動、鍵盤左右鍵、頁碼跳轉、縮圖總覽。

40 張原始圖片全部保留。閱讀器呈現封面與 37 個注音符號，共 38 頁；ㄆ、ㄜ採用作者後補的更正版，兩張原版列於「作者更正與原版圖片」。

來源：[備課抱佛腳 Facebook 貼文](https://www.facebook.com/share/p/1EhM7BSWYJ/)。圖文作品權利屬原作者，本專案不另行授予圖片使用授權。

## 新增童書

將圖片放入獨立的 assets 子目錄，新增書籍資料與書架項目。現有書籍資料位於 book.js。

## 本機預覽

在本目錄執行 `python -m http.server 8765`，開啟 http://localhost:8765。
